# laman — دفتر المبيعات

موقع عربي لإدارة المنتجات والمخزون والمبيعات. يتيح تسجيل المنتجات، الكميات المستلمة، المبيعات حسب المتجر، والكميات المسترجعة من المخزون. يعرض الميزانية والأرباح وتقريرًا لفترة محددة يمكن تنزيله بصيغة Excel.

## تشغيل المشروع محليًا

يتطلب Node.js 22.13 أو أحدث.

```bash
npm ci
npm run typecheck
npm run dev
```

افتح `http://localhost:3000` بعد بدء الخادم. لإنشاء نسخة الإنتاج محليًا استخدم `npm run build`. لتجربة التخزين محليًا، شغّل المشروع عبر `netlify dev` بعد ربطه بمشروع Netlify.

## قاعدة البيانات

نسخة Netlify تستخدم **Netlify Blobs** لحفظ المنتجات وعمليات الاستلام والبيع والإرجاع في مخزن دائم على مستوى الموقع. تُحسب أرصدة المخزون والميزانية والتقارير من هذه السجلات. تُستخدم كتابة مشروطة برقم نسخة السجل لمنع تعارض التعديلات المتزامنة. يناسب هذا التخزين دفترًا صغيرًا؛ إذا كبر عدد العمليات كثيرًا، يُنصح بنقلها إلى قاعدة بيانات علائقية.

**بيانات الإنتاج ليست ضمن هذا المستودع.** توجد تهيئة اختيارية لـ Firestore في `lib/firestore-admin.ts`، لكنها غير مفعّلة وتتطلب صلاحيات خادم خاصة بمشروع Firebase. الموقع عام دون تسجيل دخول؛ يمكن لكل من يملك الرابط تعديل البيانات وحذفها.

## الملفات المهمة

- `app/page.tsx`: واجهة الموقع العربية.
- `app/api/ledger/route.ts`: واجهة حفظ وقراءة وحذف البيانات.
- `app/ledger.css`: التصميم المتجاوب.
- `lib/export-xlsx.ts`: تصدير تقرير Excel.
