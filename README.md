# laman — دفتر المبيعات

موقع عربي لإدارة المنتجات والمخزون والمبيعات. يتيح تسجيل المنتجات، الكميات المستلمة، المبيعات حسب المتجر، والكميات المسترجعة من المخزون. يعرض الميزانية والأرباح وتقريرًا لفترة محددة يمكن تنزيله بصيغة Excel.

## تشغيل المشروع محليًا

يتطلب Node.js 22.13 أو أحدث.

```bash
npm ci
npm run dev
```

افتح `http://127.0.0.1:5173` بعد بدء الخادم. لإنشاء نسخة الإنتاج محليًا استخدم `npm run build`.

## قاعدة البيانات

يستخدم الموقع المنشور قاعدة **Cloudflare D1** عبر الربط `DB`. يحفظ جدول `products` المنتجات وأسعارها، ويحفظ جدول `movements` عمليات الاستلام والبيع والإرجاع. تُحسب أرصدة المخزون والميزانية والتقارير من هذه السجلات. مخطط القاعدة موجود في `db/schema.ts`، والهجرة الأولى في `drizzle/0000_ledger.sql`.

**بيانات قاعدة الإنتاج ليست ضمن هذا المستودع.** عند نشر نسخة مستقلة، أنشئ قاعدة D1 واربطها باسم `DB` ثم طبّق الهجرة قبل استخدام الموقع. توجد تهيئة اختيارية لـ Firestore في `lib/firestore-admin.ts`، لكنها غير مفعّلة في الموقع الحالي وتتطلب صلاحيات خادم خاصة بمشروع Firebase.

## الملفات المهمة

- `app/page.tsx`: واجهة الموقع العربية.
- `app/api/ledger/route.ts`: واجهة حفظ وقراءة وحذف البيانات.
- `app/ledger.css`: التصميم المتجاوب.
- `lib/export-xlsx.ts`: تصدير تقرير Excel.
