# laman — دفتر المبيعات

موقع عربي لإدارة المنتجات والمخزون والمبيعات. يتيح تسجيل المنتجات، الكميات المستلمة، المبيعات حسب المتجر، والكميات المسترجعة من المخزون. يعرض الميزانية والأرباح وتقريرًا لفترة محددة يمكن تنزيله بصيغة Excel.

## تشغيل المشروع محليًا

يتطلب Node.js 22.13 أو أحدث.

```bash
npm ci
npm run typecheck
npm run dev
```

افتح `http://localhost:3000` بعد بدء الخادم. لإنشاء نسخة الإنتاج محليًا استخدم `npm run build`. لتجربة قاعدة Netlify محليًا، شغّل المشروع عبر `netlify dev` بعد ربطه بمشروع Netlify.

## قاعدة البيانات

نسخة Netlify تستخدم **Netlify Database (PostgreSQL)**. يحفظ جدول `products` المنتجات وأسعارها، ويحفظ جدول `movements` عمليات الاستلام والبيع والإرجاع. تُحسب أرصدة المخزون والميزانية والتقارير من هذه السجلات. هجرة القاعدة في `netlify/database/migrations/20260929170000_ledger.sql` وتُطبّق عند النشر على Netlify.

**بيانات قاعدة الإنتاج ليست ضمن هذا المستودع.** يتطلب تشغيل Netlify Database خطة تدعمها وقد يستهلك رصيد الحساب. توجد تهيئة اختيارية لـ Firestore في `lib/firestore-admin.ts`، لكنها غير مفعّلة وتتطلب صلاحيات خادم خاصة بمشروع Firebase.

## الملفات المهمة

- `app/page.tsx`: واجهة الموقع العربية.
- `app/api/ledger/route.ts`: واجهة حفظ وقراءة وحذف البيانات.
- `app/ledger.css`: التصميم المتجاوب.
- `lib/export-xlsx.ts`: تصدير تقرير Excel.
